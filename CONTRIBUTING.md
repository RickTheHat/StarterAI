# Contributing

Thanks for helping improve StarterAI. This repository contains Markdown
instructions, not code, so contributions are changes to wording and
defaults.

## Ground rules

- Keep the documents provider-neutral. Do not tie them to one AI tool.
- Keep `1-director.md` about how the agent works, `2-standards.md` about
  technical defaults, and `3-brief.md` as a blank template.
- Keep `3-brief.md` free of project-specific content.
- Do not add secrets, private project details, or personal data.
- Keep precedence consistent: human chat instructions, then the brief,
  then standards, then the director.
- When you change a rule, update every file that mentions it (README,
  director, standards, brief).
- Package names and versions in the standards must be checked against the
  official source before you submit.

## Submitting changes

1. Open an issue describing the problem or proposal.
2. Fork, branch, and make a focused change.
3. Open a pull request that explains why, and test the change by running
   the kit on a throwaway project when it alters agent behavior.

By contributing, you agree your contribution is licensed under the MIT
License in [LICENSE](./LICENSE).

## Security reports

Do not disclose vulnerabilities in a public issue or pull request. Follow
[SECURITY.md](./SECURITY.md) for private reporting and coordinated
disclosure.
